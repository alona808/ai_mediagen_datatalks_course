Core Technical Course Requirements
The capstone project for the media generation course requires building an end-to-end, production-grade agentic system meeting the following technical criteria:
Deployment & Compute: Must run publicly on Nebius Serverless AI
 and utilize at least two GPU media models (e.g., Sana/FLUX for images, Kokoro/ACE-Step for audio, Wan 2.2 for video)
.
Agentic System & Tooling: Built around an agent with 2+ tools (MCP servers are optional)
.
Async Workloads & Object Storage: Must handle asynchronous GPU generation jobs and save all output assets into S3-compatible object storage
.
Batch Execution Targets: Requires support for batch processing with a dataset size of at least 100 records for image/audio workflows or 10 records for video workflows
.
Evaluation & Data Grounding: Includes a quantitative/human-labeled evaluation suite and deterministic quality checks (such as Whisper round-trip audio transcription matching)
. Any factual charts or figures must remain deterministic (rendered via code from data, not generated by image models)
.
Observability & Governance: Requires tracing (e.g., via MLflow or Langfuse), a defined Service Level Objective (SLO), and a detailed cost report tracking per-asset expenditure
.
Reliability & Resumability: Must demonstrate that an interrupted or killed execution resumes state from object storage without redoing completed work
